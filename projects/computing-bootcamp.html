The five decks

Each one opens as slides in a new tab

Every session is a Quarto document rendered to a self-contained reveal.js deck, so the slides, their code, and their figures are one file with nothing to install. The source .qmd for each one sits next to it in the repository.

SessionWhat it covers
01 · Introduction and resources The computing environment a new graduate student inherits: NetID and email, VPN and multi-factor access, software site licences, virtual computing, and the department's own machines and support channels.
02 · Reproducible research Case studies where the analysis failed rather than the science — a spreadsheet merge that killed a depression paper, a retracted social media study, a duplicated-data meta-analysis, the dishonesty-experiment fraud — and the reproducible stack that answers them.
03 · Version control git and GitHub from a cold start: why version control at all, configuring an identity, cloning the course materials, and the handful of commands that cover the day-to-day.
04 · Literate programming Markdown, R Markdown, and Quarto: code and prose in one document, worked through a real analysis of United Nations roll-call voting data that ships with the repository.
05 · Duke Compute Cluster Connecting to the cluster, reserving a compute node, moving files and running unix commands, using git on the cluster, and submitting a job rather than babysitting a session.

The worked example

One analysis, carried across the sessions

The literate programming session is not a tour of syntax. It runs a single analysis of UN General Assembly roll-call votes end to end — the raw roll calls, the votes, and the issue codings are all in the repository — and the same analysis exists as a Quarto document and as a Jupyter notebook, so the point being made is about the practice rather than about one toolchain.

  • Data in the repository

    UN roll calls, votes, and issue codings as CSVs, with the R script that exported them, so the analysis runs from a clone with no download step.

  • Two renderings

    The same analysis as unvotes.qmd and unvotes.ipynb, which is the cleanest way to show that reproducibility is a habit, not a file format.

  • Self-contained output

    Decks render with resources embedded, so a slide with a figure in it is still one file a year later.

Whose materials these are

These are the Department of Statistical Science's bootcamp materials, adapted by Alexander Fisher from earlier versions by Shawn Santo, Mine Çetinkaya-Rundel, and Colin Rundel. I keep a fork as the reference I work from and hand to analysts who are picking up git, Quarto, and the cluster for the first time; the slide links above point at the department's published copies.

Why it is on this site Nearly every project listed here depends on the practices this bootcamp teaches — version-controlled analysis, documents that regenerate from source, and jobs that run on a cluster rather than a laptop. It is the shortest answer to how the rest of the work is put together.

The decks, their Quarto source, and the example data are all in one repository.
