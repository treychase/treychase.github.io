Run value matrix

Runs added per event

What every outcome is worth, in runs, given the situation it happened in. A called strike costs the hitter almost nothing on 0‑0 and a great deal on 3‑2; a walk is worth more with the bases loaded than with the bases empty. This is the table underneath that: run value by count, by outs, and by which bases are occupied. Positive is runs added for the batting team.

Reading it The numbers are the encoding; the colour only sorts them at a glance, which is why the scale is blue to red rather than the site's green — green against red is the one pair a red‑green colourblind reader cannot separate. Balls and strikes are broken out by count, since that is where the count matters; every other outcome ends the plate appearance, so it carries one row.
